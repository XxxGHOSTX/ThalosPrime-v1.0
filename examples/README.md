"""
Thalos Prime Examples - README

# Example Files

## basic_session.py
Demonstrates basic session lifecycle operations:
- Creating a session
- Starting, pausing, resuming
- State transitions
- Terminating sessions

Usage:
```bash
python basic_session.py
```

## multi_session.py
Shows multi-session management:
- Creating multiple sessions
- Managing concurrent sessions
- Filtering sessions by state
- Session statistics

Usage:
```bash
python multi_session.py
```

## session_config.py
Demonstrates configuration management:
- Loading config from YAML
- Session initialization with config
- Subsystem integration
- Memory and code generation

Usage:
```bash
python session_config.py
```

## Configuration Files

### config.yaml
Sample configuration file showing:
- Session configuration structure
- Subsystem settings
- Integration options

## Session Data

The `session_data/` directory contains example session persistence files
demonstrating JSON serialization format for saved sessions.
